# Tempox Proxy
A Python proxy server with IP filtering. You can modify the proxy freely. Originally, this proxy only supported Radmin VPN, Playit.GG, Aternos, and Exaroton servers. If you have any problems, just check the Wiki.
## !!! USE IT FOR MINECRAFT OR VIDEO GAME CLIENT ONLY !!!
This proxy is intended for use only on a Minecraft client (Meteor, etc.)!
